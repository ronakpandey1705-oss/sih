Legal Metrology Guidelines

Important package declarations checked by MetroCheck.

01 — Product Name

The package should clearly identify the name or description of the commodity.

02 — Net Quantity

The net quantity should be declared using the appropriate unit of measurement.

03 — Maximum Retail Price

The maximum retail sale price should be declared in the required manner.

04 — Manufacturer / Packer

Required manufacturer, packer or importer details should be available.

05 — Consumer Information

Appropriate consumer-care information should be declared where required.

MetroCheck is a software prototype designed to assist with packaged commodity compliance.

The system uses OCR to extract information from product labels and analyzes the extracted data using compliance rules. It also provides additional consumer information about detected ingredients and nutrition.
